# KC144 — Parallel Route Crystal

```text
LOOKUP_KEY::KC144.V1::PARALLEL_ROUTE_CRYSTAL
EXECUTION::FIVE-INDEPENDENT-SIMULATIONS-THEN-DETERMINISTIC-REDUCTION
MAXIMUM_PARALLEL_WIDTH::5
MERGE_AUTHORITY::COORDINATOR-ONLY
EVERY_PATH::EVERY-TYPED-WALK-IN-THE-DECLARED-BOUNDED-UNIVERSE
TRANSPORT_CERTIFICATION::FALSE
GOVERNANCE_AUTHORITY::FALSE
PRODUCTION_TRUTH_EFFECT::NONE
```

The parallel route compiler replaces single-path narration with a bounded
product of simultaneous perspectives. Five workers may independently traverse
different regions of the same immutable KC144 graph. They cannot merge their
own outputs. A deterministic reducer validates and joins the five route
receipts in canonical route-ID order.

The result is one replayable crystal that answers five separate questions:

1. Which typed routes exist?
2. Why is each edge legal as navigation?
3. Which coordinate lenses changed, survived, appeared, or disappeared?
4. Which paths reach the same endpoint without being equivalent?
5. What may be concluded—and what remains uncertified?

## Product state

For a navigation state at GID `g`, the compiler retains:

```text
X(g) =
  ID(g)
  × NATIVE(g)
  × K4(g)
  × DLS4(g)
  × GRID16(g)
  × BR21(g)
  × KC27(g)
  × KC54(g)
  × C144(g)
  × ANGLE360(g)
  × GREAT_YEAR25920(g)
  × PRIME(g)
  × D4(g)
  × LIMINAL(g)
```

`ID(g)` is the immutable GID/grid/band/station identity generated by the frozen
atlas. Every other term is an explicitly named observer projection. A
projection may change without overwriting identity.

For `GID049`, for example:

```text
GID::049
GRID12::R05C01
DLS_TILE::[2,1]
DLS_LOCAL::[1,1]
GRID16_INJECTION::[6,1]
ANGLE360::120 degrees
GREAT_YEAR_PHASE::8640/25920 years
```

These are exact transformations of the same zero-based index `48`; they are
not competing identities.

## Typed transformation receipt

Every traversed edge emits:

```text
T =
  <domain,
   codomain,
   preconditions,
   preserved,
   changed,
   removed,
   added,
   carry,
   loss,
   residual,
   return_class,
   inverse_witness,
   standing,
   truth_effect>
```

The apparent removal of one coordinate state and addition of another describes
an observer-frame transition. It is lossless because the receipt carries both
endpoint vectors. Semantic deletion would require a nonempty `loss` field and
an explicit irreversibility witness.

Structural edges receive `STRUCTURAL_RETRACE`. Declared bridges receive
`DECLARED_RETRACE_UNCERTIFIED`. Both are graph-valid; neither certifies content
transport.

## Every-path semantics

An unbounded cyclic graph has infinitely many walks. Therefore “every path” is
undefined until the universe is fixed.

For route simulation `r`, the compiler declares:

```text
U_r = <fixed typed graph, fixed prefix, target, route budget>
```

It then computes:

- every typed target-reaching walk in `U_r`, including cycles, by dynamic
  programming;
- the exact target path count for each total hop length;
- the complete shortest-path count;
- up to the declared number of deterministic shortest witnesses;
- one canonical expanded path with step receipts and coordinate deltas.

The counts are exhaustive within `U_r`; witness expansion is intentionally
bounded. No unexpanded branch is treated as absent or false.

## Equivalence and holonomy

For routes `p` and `q`:

```text
Ω(p,q) =
  |typed_edges(p) Δ typed_edges(q)|
  +
  |nodes(p) Δ nodes(q)|
```

`Ω = 0` means equality under this declared edge/node lens. A stronger
equivalence may additionally compare transform contracts, carry, residuals,
return class, or every coordinate projection. The compiler reports all ten
pairwise comparisons among five routes and refuses to collapse a nonzero
holonomy merely because destinations match.

## Deterministic five-worker scheduler

Each task declares:

```text
<task_id,
 execution_mode,
 dependencies,
 read_set,
 write_set,
 priority,
 independent_agent_required>
```

The plan compiler:

1. rejects duplicate IDs, missing dependencies, self-dependencies, and cycles;
2. computes the dependency-ready set;
3. sorts by priority and task ID;
4. selects up to five tasks whose write sets do not conflict with another
   selected task's read or write set;
5. executes solo/coordinator/reducer tasks behind an exclusive barrier;
6. advances only after the wave is terminal;
7. merges by canonical task ID, never arrival time.

Current schedule:

```text
WAVE 1::
  SIMULATE::A_X16_CONTRACT
  SIMULATE::B_BR21_ADVERSARIAL
  SIMULATE::C_KC27_CUBE
  SIMULATE::D_KC15_SUPPORT
  SIMULATE::E_IC10_ADJUDICATION

WAVE 2::
  INTEGRATE::PARALLEL_ROUTE_CRYSTAL
```

If agent spawning is unavailable, the same immutable work envelopes execute
sequentially in canonical order. Serial and five-worker outputs must be
byte-identical. A task marked `independent_agent_required` cannot be simulated
locally; it becomes `BLOCKED_CAPABILITY`.

## Validity ladder

```text
EDGE_DECLARED
  -> NAVIGATION_PATH_VALID
  -> BOUNDED_PATH_UNIVERSE_COMPLETE
  -> DETERMINISTIC_REPLAY_EQUAL
  -/-> CONTENT_TRANSPORT_CERTIFIED
  -/-> EVIDENCE_ACCEPTED
  -/-> GOVERNANCE_AUTHORITY
  -/-> PRODUCTION_TRUTH
```

Declared bridges remain `DECLARED_UNCERTIFIED`. The compiler may reveal routes,
coordinate relationships, preserved structure, losses, and return defects. It
cannot promote claims.

## Execution

```bash
kc144-crystal parallel-routes --workers 5
```

To produce a coordinate-bound snapshot, supply all four Git coordinates:

```bash
kc144-crystal parallel-routes \
  --workers 5 \
  --immutable-commit <40-hex> \
  --immutable-tree <40-hex> \
  --compiler-commit <40-hex> \
  --compiler-tree <40-hex> \
  --output registry/parallel-route-crystal-v1.json
```
