# KC144 P45 — Reversible Edge-Retention Framework

## Purpose

P45 converts one frozen P44 edge-effect observation into a disciplined
cross-window retention decision. It does not execute another edge, mutate the
canonical graph, learn route weights, assign proposition truth, or grant
production authority.

The exact lookup key is:

`KC144.V4.6::MATH144.P45::ADMIT_CANONICAL_EDGE_EFFECT_RECEIPT_ACCUMULATE_SECOND_FORWARD_OUTCOME_WINDOW_COMPARE_ROUTE_AND_SURFACE_STABILITY_AND_DECIDE_REVERSIBLE_EDGE_RETENTION_MACROCYCLE_14`

## Whole-wave crystal

`P44 bind → effect admission → second-window intake → causal nonreuse → route comparison ∥ surface comparison ∥ nondegradation → reversible decision → replay → M12 return → P46 reseed`

The ten lanes remain separate receipts. Parallel comparison reduces latency
without collapsing route identity, surface identity, evidence standing, truth,
or authority.

## Admission and window laws

The parent is the exact public P44 release. P44 admission requires deterministic
replay plus `FROZEN_CANONICAL_EDGE_EFFECT`. The second window must:

1. occur strictly after the first window;
2. reuse no first-window event identifier;
3. contain at least five eligible task or empirical outcomes;
4. cover at least three routes and three source surfaces; and
5. contain both eligible event classes.

A continuation-only signal, test fixture, duplicated event, missing score, or
retroactive event is rejected rather than silently counted.

## Stability calculus

For each route and each source surface in the first window:

`effect = mean(candidate_score - baseline_score)`

The dimension is stable only when it reappears in the second window and:

`|effect_second - effect_first| ≤ 0.15`

This fixed bound is a framework policy, not an externally calibrated optimum.
The claim ceiling is two finite forward windows.

## Decision lattice

- `RETAIN_EDGE_REVERSIBLY`: admitted P44 effect, complete second window,
  nondegradation, route stability, and surface stability all pass.
- `RETRACT_EDGE_PROPOSAL`: the evidence is complete but measured degradation or
  instability is present.
- `HOLD`: required evidence is incomplete or the P44 effect is not admitted.

Retention does not canonicalize the edge. Retraction does not erase prior
events. Both are reversible proposals awaiting further temporal evidence and
an independent IC10 authorization process.

## Frozen public reference

`P44 effect admitted=false; first window=0; second window=0; route=HOLD; surface=HOLD; nondegradation=HOLD; decision=HOLD; graph mutations=0; truth=NONE; production authority=HOLD`

Synthetic positive, negative, reuse, diversity, tamper, and noncollapse paths
exist only to validate runtime mechanics.
