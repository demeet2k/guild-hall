A bridge from $P_{i}$ to $P_{j}$ is admitted only when:

> $$Admit\left( \beta_{ij} \right) \Leftrightarrow \left\{ \begin{matrix}
> \text{source and target carriers resolve}; \\
> \text{input and output types are declared}; \\
> \Gamma_{ij}\text{ is explicit}; \\
> K_{pres}\text{ is testable}; \\
> \Delta_{ij}\text{ is represented}; \\
> R_{ji}\text{ or irreversibility is declared}; \\
> W_{ij}\text{ is sufficient for the bridge class}.
> \end{matrix} \right.\ $$

The bridge can be:

EXACT \| PARTIAL \| LOSSY \| MULTIVALUED \| CONDITIONAL \| COMPENSATING \| MODEL \| ONE_WAY \| OBSTRUCTED

## 16.2 Return defect [<u>Back to contents</u>](#contents)

The complete return-error vector is:

> $$\boxed{\delta_{return} = \langle\delta_{id},\delta_{sem},\delta_{struct},\delta_{route},\delta_{source},\delta_{branch},\delta_{authority},\delta_{time}\rangle.}$$

The components measure:

- identity/address loss;

- semantic or predicate loss;

- packet/topology loss;

- route and order loss;

- source/provenance loss;

- branch collapse;

- authority or promotion drift;

- temporal/epoch confusion.

Exact return requires every hard component to be zero under the declared equality. Compensated return requires a bounded defect and an executable compensation map. One-way return requires an irreversibility witness.

## 16.3 Path-dependent return [<u>Back to contents</u>](#contents)

For a route:

> $$P = e_{1}e_{2}\cdots e_{n},$$

the endpoint alone is insufficient. The return object carries:

> $$\langle origin,\ endpoint,\ orderedEdges,\ pathSignature,\ branches,\ witnesses,\ defects\rangle.$$

If two routes reach the same visible endpoint, F35 asks whether the routes are coherently equivalent. Until that proof exists, endpoint equality must not collapse path identity.

## 16.4 Totalized failure [<u>Back to contents</u>](#contents)

Every partial transformation:

> $$T:X \rightharpoonup Y$$

is represented operationally as:

> $$\widetilde{T}:X \rightarrow Y \sqcup \mathcal{F}_{T}.$$
>
> $$\mathcal{F}_{T} = \mathcal{F}_{state} \cup \mathcal{F}_{runtime}.$$
>
> $$\mathcal{F}_{state} = \{\text{SINGULAR,UNDEFINED,OUTSIDE}\}.$$
>
> $$\mathcal{F}_{runtime} = \{\text{NONCONVERGENT,INACCESSIBLE},\ldots\}.$$

Runtime failures also include BUDGET_EXHAUSTED and every registered typed failure. Failure is data. A missing edge, failed test, blocked source, or nonconvergent solver remains navigable and can seed repair.

> $$\mathcal{A}_{authority} = \langle F,S,L,U,A,V,T\rangle.$$

Recency breaks ties only when the authority policy permits it.

An invalid test does not refute the claim. A passing numerical example does not prove a universal theorem. Replay agreement does not prove truth. A low residual does not establish exact equality.

# 18. QSHRINK and successor seeds [<u>Back to contents</u>](#contents)

QSHRINK is not generic summarization.

It operates only on an IC10-authorized candidate:

> $$\boxed{Q_{shrink}\left( C^{+} \right) = \langle g,r,SRC,K,\Delta,B,R,W,NEXT\rangle.}$$

Where:

- $g$: generators that can reconstruct structure;

- $r$: irreducible residue that cannot be regenerated;

- SRC: version-bound source references that can re-fetch missing bodies;

- $K$: preserved invariants and constraints;

- $\Delta$: declared loss;

- $B$: branch and tombstone carry;

- $R$: retained route prefix and return contract;

- $W$: replay and integrity witness;

- NEXT: exact continuation.

The storage law is:

> $$\boxed{X = Rec(g,r,SRC).}$$

The seed is valid only if a cold boot reconstructs the promised equivalence class:

> $$Decode(Seed) \sim_{\Gamma,\epsilon}X.$$

## 18.2 Retrieval levels [<u>Back to contents</u>](#contents)

- N0: no recovery;

- N1: topic/name only;

- N2: identity and rough role;

# 21. Mycelial learning without truth inflation [<u>Back to contents</u>](#contents)

Every executed route emits an event:

> query_id,  
> source_nodes,

> result,  
> reconstruction_score,  
> return_error,  
> evidence_state,

> timestamp,  
> replay_receipt

Route priority may update from observed retrieval and replay performance:

> $$w_{t + 1}(e) = \Pi_{\lbrack 0,1\rbrack}\left( w_{t}(e) + \eta_{s}S_{e} - \eta_{d}D_{e} - \eta_{f}F_{e} \right),$$

where:

- $S_{e}$: successful scoped replay;

- $D_{e}$: defect or return loss;

- $F_{e}$: false activation or misleading retrieval;

- $\Pi$: clipping to $\lbrack 0,1\rbrack$.

The learning boundary is:

> $$\boxed{w(e)\text{ changes routing priority, not claim truth.}}$$

Only IC10 can change promotion state. Successful routes can become named macros or fruiting bodies; failed routes remain scars and immune memory.

# 24. Reference algorithms [<u>Back to contents</u>](#contents)

## 24.1 Resolve an address [<u>Back to contents</u>](#contents)

> resolve_address(gid, epoch):  
> require 1 \<= gid \<= 144  
> row = floor((gid - 1) / 12) + 1  
> col = ((gid - 1) mod 12) + 1  
> seat = atlas\[epoch\]\[gid\]  
> require seat.grid == (row, col)  
> return seat

If epoch is absent and the GID has a cross-epoch collision, return AMBIG, not a guessed station.

## 24.2 Compile and route a query [<u>Back to contents</u>](#contents)

> route(query):  
> Q = H06.compile(query)  
> roots = H01.resolve(Q.startCoordinates, Q.temporalSelector)  
> sources = H05.resolve(Q.sourceSelector, Q.evidenceFloor)  
> candidates = H03.propose(roots, Q.goal, Q.routeBudget)  
>   
> for edge in candidates:  
> receipt = H04.audit(edge, Q.invariants, Q.boundaries)  
> if receipt.blocked:  
> preserve(receipt.defect)  
> else:  
> activate(edge)  
>   
> K = KC27.admit(Q)  
> B = BR21.plan(Q)  
> F = carriers.select(Q)  
> J = execute_parallel(K, B, F, KC54.shadow)  
>   
> return close_or_block(J, Q.returnMode)

## 24.3 Close a transaction [<u>Back to contents</u>](#contents)

> close_or_block(J, return_mode):  
> constructive = J.plus  
> hinge = J.hinge  
> conjugate = J.star  
> return_packet = build_return(constructive, hinge, conjugate)  
> defects = compare_to_source(return_packet)  
>   
> candidate = IC10.evaluate(J, return_packet, defects)  
> if candidate.state != PROMOTED:  
> return BLOCKED_WITH_REPAIR_SEED(candidate)  
>   
> seed = QSHRINK(candidate)  
> replay = SSN.M10.cold_boot(seed)  
> if replay.blocking_defect:  
> return BLOCKED_WITH_REPLAY_DEFECT(replay)  
>   
> certificate = SSN.M12.certify(seed, replay)  
> return H01.successor(certificate)
