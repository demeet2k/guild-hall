construction is no longer a 144-step procedure:

\[
\mathcal C_{144}
=H_6\sqcup(K_4\times L_4)\sqcup(O_7\times L_3)\sqcup F_{37}
\sqcup C_{10}\sqcup(2^{K_4}\setminus\{\varnothing\})
\sqcup T_3^3\sqcup S_{12}.
\]

A compact generator produces the address space. Typed transformations rotate
that space. A source overlay binds evidence without allowing symmetry,
adjacency, or repetition to create authority.

The resulting system has four layers:

| Layer | Function | Fixed law |
|---|---|---|

## Parallel navigation wave

`NAV-PASS-002` replaces seat-by-seat search with a bounded parallel wavefront.
A query supplies one or more starting GIDs, a route budget, and decay. The
engine computes:

- shortest distance from each source;
- multiplicity of shortest paths;
- nearest-source basins;
- interference where basins meet;
- activation weights;
- stable path signatures;
- a relation-weight overlay.

The overlay is metadata. It does not rewrite station records, graph relations,
evidence standing, or promotion state. For the default H06 wave at budget 18,
all 144 seats are reached; the farthest seat is reached within 15 hops.
