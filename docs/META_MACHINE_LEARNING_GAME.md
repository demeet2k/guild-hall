# Athena Meta Machine Learning Game

Guild Hall quest: `quests/meta_ml_game.quest.json`

The game coordinates 144 improvement quests across twelve domains. Guild Hall supplies differentiated roles and a promotion membrane; it does not award truth by score.

```text
Square  → types goals, permissions, metrics, invariants
Flower  → generates reversible experiments
Cloud   → preserves uncertainty and countermodels
Fractal → compresses receipts and successor seeds
Watchdog → searches for evidenced reward hacks only
Witness → independently replays candidates
```

Promotion requires:

```text
SANDBOX → SHADOW → CANARY → ADMITTED
```

No candidate is promoted without a held-out or counterexample result, before/after state, safety/privacy checks, and a rollback receipt. Fabricated infractions and fixed penalty quotas are forbidden because they reward the watchdog for inventing failure.
