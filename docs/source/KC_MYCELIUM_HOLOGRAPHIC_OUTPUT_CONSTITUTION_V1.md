Every output is a **navigation field**, not a terminal block of prose.

### §M00.K3 — Meaning of “holographic”

“Holographic” does **not** mean mechanically repeating the whole corpus inside every paragraph. It means every module contains a minimum sufficient reconstruction kernel:

\[
H_{\min}
=
\langle
ID,\ Coordinate,\ Kernel,\ Routes,\ Boundary,\ Return,\ Seed
\rangle
\]

From those seven elements, a reader or runtime can:

- locate the module;
- determine what it claims;
- reach its dependencies;
- discover what it excludes;
- return to its origin;

- reconnect it to the whole.

### §M00.K4 — Meaning of “mycelium”

The mycelium is the associative fabric of typed nodes, edges, paths, witnesses, provenance, return maps, dormant links, quarantined failures, and healing routes.

Mycelial navigation is therefore:

- **distributed**: no single linear table of contents is the only entrance;
- **typed**: a relation says what transformation or dependency it represents;
- **branch-preserving**: rejected, ambiguous, and failed routes remain addressable;
- **return-aware**: traversal records how—or whether—it can return;
- **replayable**: successful histories become named path seeds;
- **adaptive**: route weights may influence attention, never truth;
- **healing**: broken routes keep their prior identity, defect, and repair target.

### §M05.K2 — Composition law

\[

\]

the composite `T₂∘T₁` is lawful only when:

1. the output type of `T₁` matches the input type of `T₂`, or a named coercion exists;
2. their corridors overlap;
3. required invariants survive;
4. accumulated defects remain permitted;
5. branch and provenance ledgers remain attached; and
6. a return classification is recorded.

Reverse historical traversal is ordered:

\[
R_{path}=R_1\circ R_2
\]

because the last forward edge is examined first.

An exact inverse may be claimed only if all component maps are bijective on the active corridor and `R_i=T_i^{-1}`. Otherwise the return is typed as side-informed, multivalued, partial, compensated, obstructed, irreversible, or impossible.
